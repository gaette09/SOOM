# SOOM Instagram Dashboard Tasks

This folder tracks executable SOOM Instagram Dashboard tasks.

Use one task file per goal or milestone. Each task should include:

- goal
- current status
- acceptance criteria
- verification method
- blockers
- priority

Operational references:

- `docs/ops/MULTI_PROJECT_OPERATIONS.md`
- `docs/ops/PROJECT_GOALS.md`

Rules:

- Identify the dashboard project root before running project commands.
- Confirm `pwd`, `git remote -v`, and `git status --short` before work.
- Keep Instagram Dashboard tasks separate from SOOM and JAFOM tasks.
- Do not deploy, add persistent storage, or commit unless explicitly requested.
