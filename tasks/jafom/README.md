# JAFOM Tasks

This folder tracks executable JAFOM tasks.

Use one task file per goal or milestone. Each task should include:

- goal
- current status
- acceptance criteria
- verification method
- blockers
- priority

Operational references:

- `docs/ops/MULTI_PROJECT_OPERATIONS.md`
- `docs/ops/PROJECT_GOALS.md`

Rules:

- Identify the JAFOM project root before running project commands.
- Confirm `pwd`, `git remote -v`, and `git status --short` before work.
- Keep JAFOM tasks separate from SOOM and Instagram Dashboard tasks.
- Do not deploy or commit unless explicitly requested.
